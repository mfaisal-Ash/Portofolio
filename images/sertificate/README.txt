Taruh file gambar sertifikat kamu di folder ini.
Nama file harus sesuai dengan yang direferensikan di src/pages/Sertificate.jsx, contoh:
- 1.png  (untuk sertifikat "Python")
- 6.png  (untuk sertifikat "Partisipasi bootcamp cyber security")

Untuk menambah sertifikat baru: tambahkan file gambarnya di sini,
lalu tambahkan satu object baru ke array `certificates` di Sertificate.jsx.
